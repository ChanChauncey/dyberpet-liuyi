## 一、项目概述

为"六一桌宠"桌面宠物项目制作一套小红书图文教程，展示从素材制作到成品部署的完整流程。

### 目标受众
- 对桌面宠物感兴趣的网友
- 想要制作类似项目的开发者
- 喜欢AI视频生成和图像处理的技术爱好者

### 发布平台
- 小红书（图文笔记形式）
- 每张图片独立成章，可单独理解

### 内容范围
- 素材处理流程（AI生成、帧提取、抠图、部署）
- 成品效果展示
- 基础使用说明
- 跳过代码实现细节

### 第3张：AI图像生成 + 视频生成
**主题：** 素材制作第一步（两步流程）

**视觉设计：**
- 流程图形式：真实照片 → AI图像生成 → 皮克斯风格图片 → AI视频生成
- 展示真实猫咪照片（输入）
- 展示AI生成的皮克斯风格图片（中间产物）
- 展示AI生成的视频片段（最终产物）
- 工具图标：GPT image2（图像生成）+ seedance2.0（视频生成）

**文字说明：**
- 第一步：AI图像生成
  - 输入：真实猫咪照片
  - 提示词：统一的猫外观描述 + 皮克斯风格 + 绿幕背景
  - 输出：1920x1080 皮克斯风格猫咪图片
  - 工具推荐：GPT image2、nano banana
- 第二步：AI视频生成
  - 输入：皮克斯风格图片 + 动作描述
  - 视频参数：1920x1080, 24fps, MP4格式
  - 输出：猫咪动作视频
  - 工具推荐：seedance2.0、Kling

**设计要点：**
- 流程图使用两步箭头连接，清晰展示两阶段
- 三张图并排展示：真实照片 → 皮克斯风格图片 → 视频片段
- 工具图标分两组：图像生成工具 + 视频生成工具
- 颜色区分：第一步用蓝色，第二步用紫色

## 三、视觉风格规范

### 颜色方案
- **主背景**：深蓝色 #1a1a2e
- **次要背景**：深紫色 #16213e
- **主色调**：霓虹蓝 #0f3460
- **强调色**：霓虹紫 #533483
- **文字色**：白色 #ffffff
- **次要文字**：浅灰色 #a0a0a0

### 字体规范
- **标题**：粗体无衬线字体（思源黑体/阿里巴巴普惠体），24-32pt
- **正文**：常规无衬线字体，14-18pt
- **代码**：等宽字体（Consolas/Source Code Pro），12-14pt

### 布局规范
- **图片尺寸**：1080x1440px（小红书推荐竖版）
- **边距**：上下左右各60px
- **网格间距**：20px
- **圆角**：8px

### 视觉元素
- **边框**：1px 霓虹蓝色实线
- **阴影**：0 4px 8px rgba(0,0,0,0.3)
- **渐变**：线性渐变（深蓝 → 深紫）
- **图标**：线性图标，霓虹蓝色

## 四、内容要点

### 关键技术点（每张图必须包含）
1. **工具名称**：明确标注使用的工具
2. **操作步骤**：清晰的操作流程
3. **效果对比**：处理前后的对比
4. **参数设置**：关键参数说明

### 避免的内容
- 代码实现细节（跳过）
- 复杂的技术原理（简化）
- 过多的文字说明（精简）

### 必须包含的内容
- 工具名称和图标
- 操作步骤流程图
- 效果对比图
- 关键参数说明
