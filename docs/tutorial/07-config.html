个性化调整

动画速度

调整 frame_refresh 参数

互动频率

调整 act_prob 参数

解锁条件

调整 act_type 参数

# 关键配置说明

act_prob: 动画触发概率（0-1）

act_type: 亲密度解锁阈值（0-4）

frame_refresh: 帧刷新速度（ms）
